# Freelancer Invoice & Client Portal

A full-stack web application designed to help freelancers manage clients, projects, invoices, payments, files, and communication through a centralized platform.

## 📌 Overview

The Freelancer Invoice & Client Portal simplifies freelance business management by providing separate dashboards for freelancers and clients. Freelancers can manage projects, generate invoices, track payments, share files, and communicate with clients, while clients can access their assigned projects and financial information through a dedicated portal.

## ✨ Features

- **User Authentication:** Secure registration and login with role-based access for freelancers and clients.
- **Client Management:** Add and manage client details.
- **Project Management:** Create projects, assign clients, and track project budgets and deadlines.
- **Invoice Management:** Generate and manage project-linked invoices with due dates and payment statuses.
- **Payment Tracking:** Record payments and calculate paid and pending amounts.
- **File Sharing:** Upload and access project-related documents.
- **Messaging:** Enable communication between freelancers and clients.
- **Dynamic Dashboard:** Display project statistics, revenue, invoices, and pending payments.
- **Financial Reports:** Track project budgets, completed payments, and overall financial performance.
- **Data Privacy:** Restrict access to relevant client, project, and financial information based on user roles and relationships.

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm
- MongoDB database (local MongoDB or MongoDB Atlas)

## 📂 Main Modules

- **Authentication:** Registration, login, and logout.
- **Freelancer Dashboard:** Overview of clients, projects, invoices, and revenue.
- **Client Dashboard:** Access to assigned freelancers, projects, invoices, and payments.
- **Projects:** Project details, budgets, deadlines, and status tracking.
- **Invoices & Payments:** Invoice generation, payment recording, and balance calculations.
- **Files:** Project document uploads and access.
- **Messages:** Client–freelancer communication.
- **Reports:** Financial summaries and project performance.

## 🔐 Security

- Passwords are hashed using bcrypt.
- JWT-based authentication protects authenticated routes.
- Role-based access control separates freelancer and client functionality.
- Backend APIs validate access to relevant client and project data.

## 🎯 Project Objective

The objective of this project is to simplify freelance business operations by combining client management, project tracking, invoicing, payment monitoring, document sharing, and communication in one web application.
